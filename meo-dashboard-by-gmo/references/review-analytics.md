## 機能概要

クチコミの集計・分析データを確認できる機能。（基本マニュアルは未収録。詳細は追加資料収録後に更新予定）

---

## 対象グラフ・データ

クチコミ分析では主に以下の2つのグラフ・表・ダウンロードデータを管理：

- **【累計】クチコミ平均点と件数**
- **【最新】平均点と件数の推移**

---

## 表示期間と表・ダウンロードファイルの連動（2026-05-08リリース）

### 改修内容

従来は表示期間を変更した際、「【累計】クチコミ平均点と件数」グラフのみ連動して表示されていた。今回の調整で**表・ダウンロードファイルにも表示期間が連動**するようになった。また、ダウンロードファイルにグラフが追加された。

対象：【累計】クチコミ平均点と件数・【最新】平均点と件数の推移（両グラフとも同様）

### 表示期間別の集計粒度

| 表示期間 | 表・グラフの集計粒度 |
|---------|------------------|
| 1週間 | **日毎**の数値を表示 |
| 1ヶ月 | **日毎**の数値を表示 |
| 3ヶ月 | **月毎**の数値を表示 |
| 6ヶ月 | **月毎**の数値を表示 |
| 12ヶ月 | **変更なし**（従来と同一） |
| カスタム（31日間以下） | **日毎**の数値を表示 |
| カスタム（32日間以上） | **月毎**の数値を表示 |

### 改修理由

社内要望。

---

## ⚠️ 注意点

- 12ヶ月指定の場合のみ変更なし
- カスタム期間は31日以下か32日以上かで集計粒度（日毎/月毎）が切り替わる境界がある
- ダウンロードファイルにグラフが追加されたため、ファイル構成が変わっている点に注意

## クチコミ分析画面（個店）

GBPについたクチコミの数と評価の推移を確認できる画面。2つのグラフとそれに対応した表が表示される。

### グラフ1：【累計】クチコミ平均点と件数（月別）

- 折れ線グラフ：その月までのクチコミ平均点の累計推移
- 棒グラフ：その月までのクチコミ件数の累計
- グラフ下部に表形式で数値確認可能
- グラフにカーソルを合わせると詳しい数値を確認できる

⚠️ クチコミはユーザーが削除できるため、件数が下がる場合がある。

### グラフ2：【最新】平均点と件数の月別推移

- その月に届いたクチコミの平均点と件数を棒グラフで表示
- グラフ下部に表形式で数値確認可能

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/53235828394009

## クチコミ傾向分析

### 機能概要

店舗に寄せられたクチコミに含まれるキーワード・評価点・感情などを分析できる機能。キーワードごとに傾向を可視化し、改善施策のヒントを提供する。

**主な機能：**
- キーワード自由登録（1店舗最大10件、1グループ最大10件）
- 感情分析（ポジティブ・ネガティブ）・★評価点・話題数での傾向分析
- 過去データとの期間比較
- キーワードのグルーピング機能
- 他店舗（競合）とのキーワード比較（※個店のみ）

### 表示される指標

| 指標 | 内容 |
|------|------|
| A：キーワード | クチコミに含まれているキーワード |
| B：感情分析値 | キーワードが入ったクチコミの感情分析値（AWSの感情分析より計算） |
| C：話題数 | キーワードが含まれるクチコミが話題にあがった数 |
| D：評価平均点 | キーワードが含まれるクチコミの評価平均点 |
| E：検出ワード | キーワードに係る形容詞。その検出ワードを含むクチコミの比率を表示 |

### キーワード出現一覧

- キーワード数が多い順・出現率・関連ワード・ポジティブ判定等を確認可能
- キーワードを押下すると該当クチコミを表示

**表示対象：** 最新50件のクチコミのうち、「キーワード」＋「関連ワード（形容詞）」上位3つのいずれか1つ以上を含むクチコミ

### 仮登録と本登録の違い

| 区分 | 説明 |
|------|------|
| 仮登録 | 分析用の一時登録。一定期間後に削除される |
| 本登録 | 継続的な分析のための正式登録。翌朝のバッチ処理後にデータが反映される |

⚠️ 本登録後にデータが表示されない場合は翌朝のバッチ処理（データ更新）を待つ。

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/47885192284569

## クチコミハイライト分析

### 機能概要

GBPのレビュー欄上部に記載されているハイライトワード（レビューで多く含まれているワード）を抽出して画面表示する機能。

- GBP画面で表示されている件数をそのまま取得
- **データ取得：1ヶ月に1回（毎月1日）**
- ハイライトワードを押下すると関連クチコミが表示される
- 再度押下するとクチコミ表示を閉じる

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/51220654311833
