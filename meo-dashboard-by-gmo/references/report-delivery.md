## レポート配信予約画面の概要

各店舗・グループのレポートを指定日時にメール配信する予約設定画面。

### 前提・制約事項（画面上部に表示）

- **契約終了店舗**：レポート配信不可。店舗名選択もできない
- **GBPアカウント未連携店舗**：Googleキーワード／Yahoo!キーワード／SEOキーワードに関する順位レポートのみダウンロード可能。対象期間に順位データが存在しない場合は表紙のみのレポートが出力される

---

## 設定項目一覧

| 項目 | 内容 |
|------|------|
| 会社名・ID | 対象会社を選択 |
| 店舗名・ID | 対象店舗を選択 |
| グループ名 | 対象グループを選択 |
| 抽出キーワード | 「すべて」または絞り込み指定 |
| レポート名 | 最大50文字 |
| 配信レポート | 通常レポート／プレミアムレポート から選択 |
| レポート配信日時 | 「繰り返し指定」または「任意指定」のいずれかを設定 |
| レポートの形式 | PPT形式／PDF形式 から選択 |
| 資料添付 | ファイル添付が可能 |
| レポートの送付先メールアドレス | 複数の場合は「,」区切りで入力 |
| メール件名 | 任意で設定 |
| メール本文 | メッセージAなどのテンプレートから選択・編集 |

## レポート配信日時の設定方式

### 繰り返し指定（赤枠）

定期的な自動配信を設定する方式。

- 頻度例：月次
- タイミング例：毎月5日以降
- **4/9リリース**：グループプレミアムレポートの新フォーマットが先行適用済み

### 任意指定（緑枠）

特定の日時を指定して1回配信する方式。

- 配信日時：カレンダーで日付と時刻を指定
- **5/19リリース**：グループプレミアムレポートの新フォーマットが任意指定にも適用された（後述）

## 2026-05-19リリース 変更内容詳細

### 対象

レポート配信予約の「グループ版プレミアムレポート（任意指定）」

### 変更点①：新フォーマットの適用

任意指定でファイル出力した場合も、新フォーマットでレポートが作成されるようになった。

### 変更点②：レポートの種類の選択肢変更

| 変更前 | 変更後 |
|--------|--------|
| 1ヶ月レポート／3ヶ月レポート／半年レポート | **1ヶ月レポートのみ** |

3ヶ月・半年レポートは1ヶ月レポートと内容が同一だったため、選択肢から除外。

**「レポート出力画面」から直接出力するレポートは今回の改修対象外。**
新フォーマットが適用されるのは「レポート配信予約」経由の出力のみ。直接出力については別途確認が必要。

## レポート配信予約の基本手順

1. レポート配信一覧を開き、「レポート配信予約」ボタンを押下
2. グループを指定し、プレミアムレポートの設定を行う
3. 配信日時・形式・送付先メールアドレス等を設定
4. 「設定」ボタンで保存
