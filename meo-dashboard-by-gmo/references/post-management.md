## 投稿の種類

GBP投稿には以下の3種類がある。

| 種類 | 用途 |
|------|------|
| **最新情報** | どんな情報にも使えるシンプルなフォーマット。タイトルは管理用のみで実際には表示されない |
| **特典** | タイトル・クーポンコード・特典リンクなどを設定してプロモーションを発信 |
| **イベント** | タイトル・開催期間などを設定して期間限定イベントを告知 |

⚠️ グループ投稿では「COVID-19最新情報」も選択肢に表示される。

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/31060087837849

## 個店での投稿手順

1. 左メニュー【Googleデータ連携】→【Googleビジネスプロフィール】→【投稿】
2. 【新規投稿】をクリック
3. 投稿の種類を選択（最新情報 / 特典 / イベント）
4. 以下の項目を設定：
   - **投稿日時**：即時投稿 or 予約投稿（予約は翌日以降の日時指定可）
   - **投稿内容**：最新情報・イベントの内容を記述（AIアシスタントで作成も可）
   - **画像**：イベントバナーや商品画像を設定（AIで画像作成も可）
   - **ボタンの追加**：詳細情報へのアクセスや購入を促すボタン（URL設定）
   - **ハッシュタグ**：主にSNS投稿連携時に使用
   - **ワークフロー申請**：他者に確認してもらう場合に設定
5. 画面右側の投稿イメージを確認し、【登録する】をクリックして完了

**編集・削除：** 詳細下の編集マークを押下 → 修正 → 「登録」。削除は画面下部「投稿内容を削除」を選択。

⚠️ **システムの関係上、1時間以内の連続投稿はお控えください。**

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/31057211107481

## グループからの一括投稿手順

1. 【Googleビジネスプロフィール】→【投稿】→【新規投稿】
2. 投稿する**媒体**を選択（Googleはデフォルトでチェック必須）
3. 投稿フォーマットを選択し、以下の項目を設定：
   - ①投稿日時（即時 / 予約）
   - ②投稿内容（AIアシスタント利用可）
   - ③画像（AI画像作成も可）
   - ④ボタンの追加（詳細・購入へのURL）
   - ⑤ハッシュタグ
   - ⑥ワークフロー申請
   - ⑦店舗選択（投稿したい店舗を選択）
4. 【登録する】をクリック（即時は即反映、予約は指定日時に反映）

⚠️ 【下書き保存】の場合は即時・予約・WF申請含め反映されない。

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/4417475994777

## 予約投稿の仕様

- GBPの管理画面（business.google.com）では即時投稿のみ可能。**Dashboardでは最大5件まで予約投稿可能**
- 当日予約は現在時刻より**3時間先**以降の時間を指定
- 予約した投稿は**投稿時間の約1時間前まで**修正・削除可能
- 期限なし設定可能（何年先でも予約設定可）

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/4408216263449

## 繰り返し投稿機能

同じ内容を自動的に繰り返し投稿する設定。

⚠️ **Googleのみ対応。ワークフロー申請は利用不可。**（Googleによる重複コンテンツ判定を避けるため、投稿済みの投稿を削除してから同内容を再投稿する仕様）

### 繰り返しパターン

| パターン | 設定内容 |
|---------|---------|
| 週 | 「1週間毎」または「2週間毎」＋曜日（月〜日）を指定 |
| 月（日付） | 「1・2・3ヶ月」＋日付（1〜31・月末）を指定 |
| 月（曜日） | 「1・2・3ヶ月」＋第N週＋曜日を指定 |

- 終了日：任意設定可。未設定の場合は繰り返し継続
- 投稿エラー時と繰り返し投稿開始時にお知らせ通知あり

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/56295491162521

## 投稿後のステータス一覧

| ステータス | 意味 |
|-----------|------|
| **投稿済** | 投稿が成功した状態 |
| **Google処理中** | MEO DashboardからAPIで投稿成功したがGoogle側での表示確認待ち（Dashboardでは対応不可） |
| **投稿待ち** | 予約済みで投稿バッチにまだ入っていない状態 |
| **予約中** | 投稿バッチに入り投稿待ちの状態 |
| **データ処理失敗** | 投稿バッチ処理時間が来ても予約投稿をバッチに入れられなかった |
| **API投稿エラー** | APIでの投稿失敗（LOCAL_POST_STATE_UNSPECIFIEDによる不明原因エラーも含む） |
| **投稿処理エラー** | 投稿途中でエラーが発生し投稿不可 → 内容確認後に再投稿 |
| **投稿拒否** | Googleが投稿を拒否（電話番号・メールアドレス含有等） → 内容確認後に再投稿 |
| **投稿削除** | GBP上で投稿が完全削除された状態（ユーザーまたはGoogle側による削除） |

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/11578133605913

### 機能概要

InstagramへのSNS投稿をGBPに自動連携する機能。Instagram→GBPの逆パターン連携のうち、写真に特化した設定。

### Instagramアカウント連携画面の列構成

| 列名 | 内容 |
|------|------|
| Facebookページ名 | 連携するFacebookページ |
| メールアドレス | アカウントのメールアドレス |
| アカウント名 | Instagramアカウント名 |
| IG→GBP写真管理 | チェックONでInstagram写真をGBPに連携 |
| **写真の投稿順序** | GBPに反映する写真を指定（2026-05-21追加） |
| ハッシュタグなし投稿 | ハッシュタグを除外して投稿するか |
| 電話番号投稿の除外 | 電話番号を含む投稿のブロック設定 |
| 連携対象 | 連携対象かどうか |
| 分析連携対象 | 分析連携の対象かどうか |
| 連携ステータス | アクティブ等の状態 |

## IG→GBP写真管理：写真の投稿順序設定（2026-05-21リリース）

### 概要

Instagramの1投稿に複数枚の写真が含まれる場合に、GBPへ反映する写真を店舗単位で制御できる機能。

### 入力条件

- 「**IG→GBP写真管理**」チェックボックスがONの行のみ入力可能
- 未入力の場合は**すべての写真がGBPに投稿**される（従来通りの挙動）

### 入力ルール（2パターン）

**【A】反映したい写真の番号をカンマ区切りで指定**

投稿の何枚目の写真をGBPに反映するかを番号で指定する。

| 入力例 | 意味 |
|--------|------|
| `1` | 1枚目のみ |
| `2,3` | 2枚目と3枚目 |
| `2,3,4` | 2・3・4枚目 |

**【B】最後の写真を除外してGBPに反映**

→ 「**最後の写真除外**」と入力する

### ⚠️ 重要な制約

- **【A】と【B】の併用は不可**（番号指定と「最後の写真除外」は同時に使えない）
- 改修理由：MDC顧客要望

## 投稿 URL事前設定機能（2026-05-14リリース）

### 概要

新規投稿作成時に「ボタンの追加」で設定するURLを事前登録しておくことができる機能。投稿のたびにURLを手入力する手間を省ける。

### 設定場所

**店舗詳細画面**に「投稿URL事前設定」欄を追加。
- 投稿機能がONになっている店舗のみ表示される
- URLは**最大10個**まで登録可能（カンマ区切りで登録）

---

### 個店 新規投稿画面での利用

「ボタンの追加」欄で以下のいずれかを選択：

| 選択肢 | 内容 |
|--------|------|
| URL 手動入力 | その都度URLを直接入力 |
| 投稿URL事前設定を使用 | 事前登録済みのURLから選択 |

- 事前設定が**未設定の場合**は「投稿URL事前設定を使用」は選択不可
- 複数URLを事前登録している場合は**プルダウンで選択**

---

### グループ 新規投稿画面での利用

「ボタンの追加」欄で以下のいずれかを選択：

| 選択肢 | 内容 |
|--------|------|
| URL 手動入力 | その都度URLを直接入力 |
| 投稿URL事前設定を使用 | 「登録URL選択」からURL選択 |

「投稿URL事前設定を使用」を選択後、「登録URL選択」をクリックするとモーダルが表示され、以下の2方式から選択：

**① 投稿URL事前設定を利用**
- グループ内の各店舗に登録されているURLの一覧から選択
- 任意のURL1つを選択し「選択する」で設定

**② URL新規入力・登録を利用**
- 投稿画面上で、そのグループ専用のURLを新たに登録できる
- 「URL」と「URL登録名」を入力して「登録する」で登録
- 登録済みURLのリストにチェックして「削除する」で削除可能
- 登録したURLから任意の1つを選択して設定

---

### グループ 一括インポートでの利用

- 「投稿URL事前設定リスト」のダウンロードが可能
- ダウンロードしたリストのURLを参照して、一括インポートファイルの「ボタンURL」欄にURLを入力する

## ⚠️ 注意点

- Instagram連携（単体）はInstagram→GBP投稿のみで、MEO Dashboardの投稿画面からInstagramへの投稿はできない
- GBPに直接画像を投稿した場合、システムによる重複チェックが行われない。重複画像が登録される可能性があるため、同じ画像を投稿しないよう注意
- 投稿URL事前設定は投稿機能がONの店舗のみ利用可能

## 詳細文AIアシスタント

AIが投稿用テキストを生成する機能。投稿文章を作成する時間がない場合に活用できる。

### 使用手順

1. 【Googleデータ連携】→【Googleビジネスプロフィール】→【投稿】
2. 新規投稿作成画面から【詳細文AIアシスタント】をクリック
3. 文字数（400〜1200字の間で指定可）と生成指示内容（伝えたいポイント）を入力
   - 例：「店舗リニューアルオープンのお知らせ」「閉店セールの訴求」等
   - 生成指示内容を詳細に書くほどビジネスに沿った文章が生成される
4. 生成完了後、候補が3つ表示される
5. 最も近い候補の【◯】を選択→【登録する】をクリック
6. 細かい修正・改行を行って完成

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/24667727895449

## 画像AIアシスタント

AIが投稿用画像を生成する機能。投稿画像が手元にない場合に活用できる。

### 使用手順（簡易設定）

1. 新規投稿作成画面から【画像AIアシスタント】をクリック
2. 作成したい画像イメージを文章で入力（生成指示内容）
3. 場所（国内/海外・屋内/屋外）を任意で選択
4. 【写真】または【イラスト】を選択
5. 著作権を確認し【上記を確認しました】にチェック→【作成する】をクリック
6. 候補が2つ表示される→【◯】で選択→【登録する】をクリック

**詳細設定：** 簡易設定の内容に加えて「必須アイテム・服装・表情・登場人物・雰囲気」も設定可能（任意）。

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/30933450522521

## ハッシュタグAI生成機能

投稿内容をもとにAIが関連ハッシュタグを自動生成し、投稿に付与できる機能。

**対象：** 個別店舗・グループ

### 使用手順

1. 新規投稿画面で各項目を設定し投稿内容を入力
2. 投稿内容が入力された状態で「ハッシュタグAI生成」ボタンをクリック
3. ポップアップにハッシュタグ候補が表示される（最大10個を選択可）
4. 「保存する」ボタンをクリックして投稿に付与

⚠️ 文字数制限：Google 1500文字以内、Yahoo! 330文字以内（投稿内容+ボタンURL+ハッシュタグを合算）

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/45898921343513

## RSSブログ連携

店舗のオウンドメディアやブログのRSSフィードを連携し、GBP・Yahoo!プレイスの投稿に自動反映する機能。

### 設定手順

1. 左メニュー【Googleデータ連携】→【Googleビジネスプロフィール】→【投稿】→【RSSブログ】を選択
2. 以下の項目を設定：
   - **RSSフィードURL**：オウンドメディア・ブログのRSS+xmlのURL
   - **取得記事数**：最大5件
   - **取得開始日**：この日以降の記事のみ対象
   - **画像取得方法**：「OGPで画像を取得」または「最初の画像を使用」
   - **投稿媒体**：Google・Yahoo! から選択
3. 「保存する」をクリックして完了

**動作仕様：** 毎日深夜1時に前日の投稿をバッチ処理で取得・反映。

⚠️ OGPで画像を取得する設定でOGPが設定されていない記事は画像が取得されない。
⚠️ RSSブログ連携ではボタンの追加はできない。
⚠️ RSS取得をストップしたい場合はRSSフィードURLを空にして「保存する」をクリック。

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/47702403484569

## 商品投稿

⚠️ **MEO DashboardからはGBP商品投稿は行えない。** Googleビジネスプロフィールの管理画面から直接投稿する必要がある。

### GBPでの商品登録手順

1. GBPを管理しているアカウントでログイン
2. GBPを表示
3. 「商品を編集」または「追加」ボタンを選択
4. 詳細情報を入力（商品/サービスは必須・58文字以内）
5. 登録後に「承認」ステータスになっているか確認（ポリシー違反の場合は不承認になりマップに表示されない）

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/4408893659417
