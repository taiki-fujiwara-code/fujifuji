## 機能概要

MEO Dashboardが自動でGoogle検索結果を取得し、対象店舗の順位を計測する機能。（詳細は基本マニュアル収録後に追記予定）

---

## 順位取得ロジック 微調整（2026-05-07リリース）

### 問題の背景

Googleの検索結果（特にローカルパック）では、結果の各店舗に「A」「B」「C」などのアルファベット接頭辞が付与されるケースがある。

この接頭辞が付いた状態でビジネス名を文字列判定しようとすると、正しく店舗名を識別できず、順位取得が失敗するケースが発生していた。

### 対応内容

接頭辞（A・B・C等）が付与されている場合でも、ビジネス名を正しく判定できるよう順位取得ロジックを調整。

### 対象ケース（スクリーンショット例）

Google検索結果のローカルパック表示において、地図上のピンと店舗一覧にA・B・Cのラベルが付与されるパターン。

```
A ○○○○（店舗名）
  営業中・営業終了：19:00

B ○○○○（店舗名）
  営業中・営業終了：19:00

C ○○○○（店舗名）
  営業中・営業終了：19:00
```

このような表示形式でも順位を正しく取得できるようになった。

### ⚠️ 注意点

- この調整以前（2026-05-07以前）に取得された順位データで、接頭辞起因の誤判定が発生していた場合、過去データの補正は行われない
- 顧客から「順位が急に変わった」「以前と数値が違う」という問い合わせが来た場合、このリリース前後の期間かどうかを確認するとよい

### 順位取得タイミング

1日2回、順位を取得し、**良い方の順位をDashboardに表示**する。

| 取得回 | 時間 | 取得元 |
|--------|------|--------|
| 1回目 | 10時ごろ | Google検索（ブラウザ）での順位 |
| 2回目 | 20時ごろ | Google Mapでの順位 |

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/19078033715609

### 順位表示の特殊ステータス

| 表示 | 意味 |
|------|------|
| **ローカル検索表示なし** | 検索結果にマップ表示がされていない状態 |
| **競合ナレッジパネル** | 検索結果に競合他社1社のみのナレッジパネルが表示されている状態（マップなし・1社のみ） |

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/4408831019417

## 順位チャートの確認方法（基本操作）

個店画面の【順位レポート】→【順位チャート】から確認。

### 画面内の各セクション

| セクション | 内容 |
|-----------|------|
| **キーワード別前日比ランキング** | 設定キーワードの前日順位と前日比を表示 |
| **キーワード別デイリーランキング** | 任意期間のキーワード順位推移。デフォルト「20位以内のみ」表示。「すべて」「10位以内のみ」「3位以内のみ」に切替可能 |
| **全キーワード平均値デイリーランキング** | 設定キーワードの順位平均値の推移 |
| **競合キーワード別デイリーランキング** | 同エリア・キーワードで検索した競合店舗の順位 |

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/31943143555737

## キーワード分析（店舗ページ限定機能）

⚠️ **店舗ページ限定の機能。**

**アクセス方法：** 左メニュー【順位レポート】→【キーワード分析】

### 表示される指標

| 指標 | 内容 |
|------|------|
| 最高順位 | 当月で最も順位の高いキーワードと検索エリア |
| 最低順位 | 当月で最も順位の低いキーワードと検索エリア |
| 3位以内率 | 3位以内に入った回数 ÷（キーワード数 × 日数）|
| GBPの検索総数 | 直近1ヶ月のキーワード検索数の合計値 |
| 3位以内率のキーワード別推移（Google） | 直近5ヶ月のキーワードごとの3位以内率推移 |
| 直近3ヶ月ランキング4位〜10位のキーワード | 直近3ヶ月の最高順位が4〜10位のキーワード一覧 |
| GBP表示の検索語句数（直近5ヶ月） | 直近5ヶ月においてビジネスプロフィール閲覧につながった検索語句数 |

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/32867624521369

## カレンダー順位レポート（店舗ページ限定機能）

⚠️ **店舗ページ限定の機能。**

GBPにユーザーが流入した際に使用した検索キーワードの1ヶ月間レポートをカレンダー形式で確認できる。

**アクセス方法：** 左メニュー【順位レポート】→【カレンダー順位レポート】

**設定できる項目：** 対象年月・検索キーワード・対象媒体

**「拡大表示」：** 1ヶ月分の順位を一覧で確認可能

**日次順位レポート：** 日ごとのキーワード順位をGoogleマップのキャプチャで確認できる

**カレンダー順位レポートに掲載している順位について：**
Googleマップでの掲載順位を表示している。

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/32868419793433
