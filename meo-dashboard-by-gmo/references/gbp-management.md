## 機能概要

MEO Dashboard上でGoogleビジネスプロフィール（GBP）の店舗基本情報を編集・管理する機能。
変更はDashboard → GBPの方向に同期される（GBP上の変更はDashboardに反映されない）。

**アクセス方法（個店）：**
左メニュー【Googleデータ連携】→【Googleビジネスプロフィール】→【店舗基本情報】

---

## ヘルプカテゴリ「店舗基本情報」の構成

| セクション | 内容 |
|-----------|------|
| 個店 | 個店画面での基本情報編集（10記事） |
| グループ | グループ一括編集（Excelまたは◯☓表）（10記事） |
| 改ざん防止 | 改ざん防止機能の設定・ログ |
| その他 | 更新履歴・SNSプロフィール形式・FAQ |

## 個店での基本情報編集

### ビジネス情報（概要文）

店舗の簡単な説明文を設定できる項目。

**記載すべき内容（Google公式ガイドラインより）：**
- 提供している商品やサービス
- 独自のセールスポイント
- ビジネスの紹介・由来・歴史
- ユーザーが参考にできるその他の情報

**記載できない内容：**
- 特別キャンペーン・特別料金・特典を過度に強調するコンテンツ
- URLやHTMLコード

**注意事項：**
- 改行は反映されない
- 単なるキーワードの羅列は避ける（不自然に入れ込むと悪影響）

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/31275712988825

---

### 営業時間の設定方法

**手順：**
1. 左メニュー【Googleデータ連携】→【Googleビジネスプロフィール】→【店舗基本情報】を選択
2. 【営業時間】項目を確認
3. 設定内容に応じて以下を入力：
   - 営業中時間を登録する場合：【営業】にチェックを入れ、開店・閉店時間を入力
   - 定休日を登録する場合：【定休日】にチェックを入れる
   - 24時間営業の場合（ホテル等）：【24時間営業】にチェックを入れる
4. 画面下部の【登録する】を押して完了

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/31077967746073

### 特別営業時間の設定方法

大型連休・年末年始など、通常の営業日・定休日と異なる営業時間を設定する機能。

**手順（個店）：**
1. 左メニュー【Googleデータ連携】→【Googleビジネスプロフィール】→【店舗基本情報】を選択
2. 営業時間設定箇所の下部にある【特別営業時間】から設定

**定休日を設定したい場合：**
- 日付を選択し、スライダーを青にする。時間入力は空白のままでOK

**営業日を設定したい場合：**
- 日付と時間を入力し、スライダーを青にする

**日をまたぐ場合：** 2日間に分けて登録
- 例）2024/12/28 12:00 00:00、2024/12/29 00:00 02:00

**一括登録（個店・グループ共通）：**
1. 「一括追加」を選択
2. 日付と時間を設定し保存ボタンを押下
3. 画面下部の【登録する】を押下

**削除方法：** スライダーをON（青）にし、脇の「✕」を押す

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/4408216066457

### 臨時休業の掲載方法

**適用ケース：** 連続して7日間以上休業する場合、または期間不明で休業する場合は臨時休業に変更する。

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/4408634087449

### サービスの追加方法

店舗で実施しているサービス名と詳細を表示できる項目。

⚠️ **スマートフォンのみで表示。パソコンでは表示されない。**

**手順：**
1. 左メニュー【Googleデータ連携】→【Googleビジネスプロフィール】→【店舗基本情報】→【サービス】を選択
2. 各項目の編集：
   - ①：メインカテゴリー・サブカテゴリーが表示される。各カテゴリーの下にサービスを追加可能
   - ②：【鉛筆マーク】または【追加】からサービス名と詳細を入力
   - ③：Googleが自動提示するサービス候補から選択も可能
3. 【登録する】を押して完了

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/37549749732249

### SNSプロフィールの設定

個店・グループ共に【店舗基本情報】よりSNSプロフィールの設定が可能。

**各SNSのURL記載形式：**

| SNS | URL形式 |
|-----|---------|
| Facebook | https://www.facebook.com/{ユーザー名} |
| Instagram | https://www.instagram.com/{ユーザー名} |
| LinkedIn | https://www.linkedin.com/in/{ユーザー名} または /company/{ユーザー名} |
| Pinterest | https://www.pinterest.com/{ユーザー名} |
| TikTok | https://www.tiktok.com/{ユーザー名} |
| X（旧Twitter） | https://www.twitter.com/{ユーザー名} |
| YouTube | https://www.youtube.com/channel/{ユーザー名} 等 |

**Googleが自動登録したSNSの削除：**
Googleに削除申請が必要。対象GBPの管理権限を持つGoogleアカウントでログインの上、以下URLより申請。
https://support.google.com/business/gethelp
※削除までにはお時間がかかる場合あり

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/33452890249369

### 【ホテル】店舗基本情報の編集（個店）

ホテルカテゴリーの店舗では、通常の店舗基本情報に加えて「ホテル店舗基本情報」タブが表示される。

**ホテル専用編集項目：**

| 項目 | 入力形式 |
|------|---------|
| A：ホテル名 | 店舗名表示 |
| B：ビジネス名 | GBP登録ビジネス名 |
| C：最終改装年 | 西暦4桁・半角数値 |
| D：客室数 | 半角数値 |
| E：階数 | 半角数値 |
| F：チェックイン・チェックアウト時間 | 00:01〜23:59。例：15:00 |
| G：最大子供年齢 | 子供料金で宿泊できる年齢 |
| H：子供宿泊無料枠の上限数 | 1世帯あたりの上限 |
| I：子供無料宿泊 | 無料の場合はボタンを選択 |
| J：ダウンロード | 登録情報のダウンロード |

**注意：** ホテル基本情報画面でのチェックボックスON→OFF変更は直接不可。変更は一括インポートファイルにて対応。

**対象となるホテル・旅館等（Googleのホテル物件）：**
ホテル・モーテル・ホステル・リゾートホテル・山小屋・キャンプ場＆コテージ・長期滞在型ホテル・ラブホテル・イン・B&B・ファームステイ・旅館・カプセルホテル・宗教宿泊施設・民宿 等

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/52947603688601

## グループでの一括編集

### 一括編集（Excel）

グループ単位でGBP店舗基本情報をExcelで一括設定・編集できる。

**手順：**
1. MEO DashboardロゴのHm横の店舗名クリック→グループ→任意のグループ選択
2. 左メニュー【Googleデータ連携】→【Googleビジネスプロフィール】→【店舗基本情報】
3. 【ダウンロード】→【グループ一括登録テンプレート】を選択
4. 【ダウンロード・インポート処理管理】画面からExcelをダウンロード
5. Excelを編集（GoogleシートとYahoo!シートに分かれている）
   - Google情報更新：【(Google)店舗基本情報】シートのE列【更新媒体】を「Google」で設定
   - Yahoo!情報更新：【(Yahoo!)店舗基本情報】シートのE列を「Yahoo!」で設定
   - 両方同時：両シートを更新しE列を「Google・Yahoo!」で設定
6. DashboardでExcelをインポートして完了

**特別営業時間の記載方法（Excel）：**
- 定休日：`2023/11/06 定休日、2023/11/07 定休日`（「、」区切り）
- 営業時間：`2023/11/06 11:00 20:00、2023/11/07 12:00 19:00`
- 日をまたぐ場合：`2024/12/28 12:00 00:00、2024/12/29 00:00 01:00`
- スペースは半角。時刻間に文字・記号不要（半角スペースのみ）

⚠️ **誤って情報を削除しセルが空白のままインポートした場合、情報が削除される。**

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/29604184006425

## その他FAQ

### 閉業時の対応
閉業した店舗は Dashboard から「閉業」ステータスへ変更する。

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/4408633968153

### GBP上で基本情報を編集してもDashboardに反映されない
Dashboard → GBPへの同期は行われるが、GBP → Dashboardへの同期はGoogleの仕様上存在しない。基本情報の変更は必ずDashboard上から行う。

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/5633688946713

### テイクアウト・宅配等の営業時間設定
テイクアウトや宅配等の副次的な営業時間も設定可能。

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/4408642257817

### 店舗基本情報 更新履歴
Dashboard上での基本情報変更履歴を確認できる機能。

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/47789711305113
