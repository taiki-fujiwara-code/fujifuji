## 機能概要

MEO Dashboardで管理しているFAQ情報をWebサイトへ連携表示する機能。管理画面から発行した専用タグをWebサイトの対象ページに設置するだけで、FAQコンテンツが自動表示される。

**開発背景**：GBPの仕様変更でFAQ（Q&A）をオーナーが編集できなくなった現在、ホームページ上にFAQを用意しておくことは集客・信頼構築において非常に重要。MEO Dashboard上での一元管理＋ワンタグ実装により、運用効率化と情報更新の最適化を実現。店舗サイトのFAQはWebサイト側で個別管理されるケースが多く、更新作業・情報管理の負荷が課題だった。

**リリース日**：2026-05-26

## 機能解放の手順（利用開始前の必須設定）

HP FAQ管理機能を利用するには、会社・店舗の両方で機能解放が必要。

### 会社の機能設定

## 個店 HP FAQ管理

### FAQ登録・編集（「FAQ登録・更新」タブ）

| 項目 | 説明 | 制限 |
|------|------|------|
| A：FAQ表示順序 | ドラッグ＆ドロップで並び順を変更 | — |
| B：質問 | 質問テキストを入力 | 最大100文字 |
| C：回答 | 回答テキストを入力 | 最大300文字 |
| D：質問の追加 | 「＋質問を追加」ボタンで質問を追加 | — |
| E：登録する | 全項目更新後に押下して保存 | — |

**操作の流れ**：質問・回答を入力 → 必要に応じて「質問の追加」で追加 → 「登録する」で保存

### デザイン設定とタグ発行（「デザイン・タグ発行」タブ）

Webサイトに埋め込むFAQのデザインを設定し、タグを発行する。

| 項目 | 説明 |
|------|------|
| A：タイトル指定 | 質問のタイトルを指定あり・指定なしで設定。タイトルは最大20文字 |
| B：デザイン選択 | **ライン型・カード型・シンプル型**の3種類から選択 |
| C：境界選択 | 見出しとFAQエリアの境界線あり・なしを設定 |
| D：QAマークの設定 | 質問・回答にQAマークを表示するか設定 |
| E：タイトルテキスト | タイトルのテキストカラーを設定 |
| F：各種カラー設定 | 質問テキスト・質問背景色・回答テキスト・回答背景色を設定 |
| G：フォントサイズ | タイトル・質問・回答のフォントサイズを設定 |
| H：デザインイメージ | A〜Gの設定のプレビューを確認できる |
| I：発行する | タグを発行するボタン |
| J：タグ | コピーしてWebサイトの `<body>` タグ内の表示したい箇所に貼り付け |

**操作の流れ**：デザイン設定 → プレビューで確認 → 「発行する」でタグ発行 → タグをコピーしてWebサイトに貼り付け

## グループ HP FAQ管理

グループ画面では**FAQの登録のみ**が可能（デザイン設定は個店画面で行う）。

### 操作手順

1. 「ダウンロード」ボタンでテンプレートファイル（Excel）を出力
2. ダウンロードしたExcelファイルを編集（FAQ内容を入力・更新）
3. 「一括インポート」でファイルをアップロード

## 顧客説明のポイント

**「FAQをWebサイトに自動表示したい」という要望への回答：**
HP FAQ管理機能を使えばMEO Dashboard上でFAQ内容を管理し、専用タグを貼り付けるだけで自動反映される。WebサイトのHTML改修不要で、Dashboard側の更新がそのままWebに反映される。

**「複数店舗にFAQを設定したい」という要望への回答：**
グループ HP FAQ管理からExcelテンプレートを使った一括インポートが可能。

**「デザインをカスタマイズしたい」という要望への回答：**
ライン型・カード型・シンプル型の3種類から選択でき、カラー・フォントサイズも調整可能。

**⚠️ 注意点：機能解放が必要**
利用開始前に会社設定・店舗設定の両方でHP FAQ管理のチェックボックスをONにする必要がある。片方だけでは機能が使えない。
