## クチコミ管理画面の概要

MEO Dashboard上でGoogleクチコミの確認・返信・分析ができる機能。個店単位とグループ単位の両方で利用可能。

### NEWマーク・感情分析

- 新着クチコミが入った場合：メニュー右横に「NEW」マークが表示される
- ネガティブなクチコミが入った場合：メニュー右横に「！」マークが表示される

---

## グループ クチコミ管理画面

### クチコミ一覧の表示項目

| 列名 | 内容 |
|------|------|
| 投稿者名 | クチコミ投稿者のアカウント名・アイコン |
| 評価 | 星評価（5段階） |
| コメント | クチコミ本文（クリックで全文表示） |
| 初回投稿日 | クチコミが最初に投稿された日時 |
| 最新更新日 | クチコミが最後に更新された日時 |
| 最新返信日 | 最後に返信した日時 |
| 店舗名 | 対象店舗名 |
| 返信 | 返信済み（「済」）または未返信の状態 |
| 感情分析 | AIによる感情分析スコア（例：ポジティブ 96%、普通 4%） |
| WF承認 | ワークフロー承認状況（「WFなし」「承認済」「却下」等） |

### 絞り込み・検索・ダウンロード

- 日付軸（初回投稿日 / 最新更新日）・店舗・評価で絞り込み
- 「ダウンロード」ボタンで絞り込みしたクチコミをExcelエクスポート

## 個店での一括返信（Excel経由）

1. 左メニュー【Googleデータ連携】→【Googleビジネスプロフィール】→【クチコミ管理】
2. 【ダウンロード】でクチコミをExcelにダウンロード
3. Excelで確認：
   - B〜D列：投稿者名・★数・コメント
   - K列：返信ステータス（返信済：「済」、未返信：「未」）
4. 返信ステータスが「未」のクチコミに対して【L列】に返信内容を入力
5. Excelを保存
6. Dashboard に戻り【一括インポート】から作成したExcelを選択してインポート

⚠️ インポート完了後、即時でクチコミが返信される。Google側の処理状況によっては数分かかる場合あり。
⚠️ ワークフロー機能を使用する場合は【ワークフローを使用】から承認者を選択してからインポート。

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/31272423656217

---

## グループでの一括返信（Excel経由）

1. グループ管理画面のメニュー【クチコミ一括返信・自動返信】をクリック
2. 【クチコミ一括返信】でフォルダ・期間・媒体（Google/Yahoo!）を設定し【ダウンロード】
3. Excelで確認：
   - B列：店舗名
   - I〜K列：投稿者名・★数・コメント
   - R列：媒体
   - S列：返信ステータス（「済」/「未」）
4. ステータスが「未」のクチコミの返信内容を【T列】に入力
5. Excelを保存
6. Dashboard に戻り【一括返信インポート】から作成したExcelを選択してインポート

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/28754870396185

## 自動返信機能

### 個店の自動返信設定

★の数やコメントの有無など事前設定した条件に合致するクチコミが投稿された際に、自動で返信する機能。

**設定手順：**
1. 【Googleビジネスプロフィール】→【クチコミ管理】を開き「返信パターン・自動返信」をクリック
2. 各項目を選択・入力して返信パターンを登録
3. 「自動返信」に☑を入れる

**自動返信実行タイミング：** 毎日10時〜22時の間、**2時間おき**に処理

⚠️ 返信パターンの登録のみ行う場合は「自動返信」の☑を外すと登録のみで返信は行わない。

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/18103444215193

---

### グループの自動返信設定（Excel経由）

**設定手順：**
1. 【Googleデータ連携】→【Googleビジネスプロフィール】→【クチコミ一括返信・自動返信】にアクセス
2. 「クチコミ自動返信」の【ダウンロード】でテンプレートをダウンロード
3. テンプレートに条件を設定：
   - 投稿パターン名（管理用名称）
   - 感情分析評価（ポジティブ/ネガティブ等）※AWSの感情分析を使用
   - 評価点（星1〜5）
   - コメントの有無
   - 返信内容
   - 自動返信：「○」で自動返信ON
4. 【自動返信一括インポート】でファイルをインポート

⚠️ **現時点でグループ画面からの自動返信設定の削除機能はない。** 使用しない設定は「自動返信」欄を「✕」にして自動返信をOFFにする。
⚠️ 必ず最新のテンプレートをダウンロードして設定すること。

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/53392107231513

## クチコミAI返信アシスタント（グループ）

AIがクチコミのコメントや星の数を考慮して、自動で返信コメントを作成する機能。

**手順：**
1. グループ管理画面【クチコミ一括返信・自動返信】をクリック
2. 【クチコミAI返信アシスタント】でフォルダ・期間・媒体を設定
3. 「AI返信アシスタント条件設定」で各項目を選択：

| 設定項目 | 選択肢 |
|---------|--------|
| 文字数 | 150〜400文字 |
| 評価の星 | コメントと併せて星の数を考慮するか否か |
| 投稿者名 | 「不要」「○○様」「○○さん」の3択 |
| 返信者役職 | 「指定なし」「リーダー」「マネージャー」「店長」「オーナー」「社長」「部長」の7択 |
| 冒頭店舗名お礼文 | ☑で「この度は、〇〇へご来店いただきありがとうございます。」を冒頭に追加 |
| 末尾店舗署名 | 返信文末尾にビジネス名を記載するか |
| 当店表記にする | AI生成文の「弊社・当社」を「当店」に変更 |
| 投稿言語でAI生成 | 例：英語クチコミ→英語で返信 |

4. 「登録する」→【AI返信文章ダウンロード】でExcelをダウンロード
5. T列【返信内容】のAI生成コメントを確認・修正
6. Excelを保存
7. Dashboard に戻り【一括返信インポート】からExcelをインポート

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/28756033534105

## Dashboardへのクチコミ反映タイミング

### 新規連携時

連携した日の**23時30分**にすべてのクチコミデータを取得し、翌日Dashboardに反映。

### 連携後の定期取得

| タイミング | 内容 |
|-----------|------|
| **月1回**（10〜25日のランダム） | 1店舗1回、すべてのクチコミを全件取得 |
| **毎日6回**（5・8・11・14・17・20時） | 3時間おきにバッチ処理でクチコミ取得と自動返信処理 |
| **毎日23時30分** | DashboardとGBPのクチコミ件数を比較し、不足があれば全件取得（自動返信は行わない） |

**5時バッチの特記仕様：** 前日20時〜当日5時までのクチコミデータ取得と自動返信処理を行う。

⚠️ バッチ処理の時間は目安であり、反映までにラグが生じる可能性がある。

### 「全クチコミ取得」ボタン

クチコミ一覧画面の右上にある「全クチコミ取得」ボタンを押すと手動で全件取得できる（クリック回数制限なし）。GBP上でクチコミ返信を行い当ツール上にデータがない場合などに利用。

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/21007623734809

## 「全クチコミ取得」ボタン（グループ）（2026-05-26リリース）

グループ クチコミ管理一覧画面の右上に「全クチコミ取得」ボタンを追加。

**動作仕様：**
1. ボタン押下後、クチコミ取得処理を開始
2. 押下直後にメッセージを表示：「全クチコミを取得しています。完了後、ベル通知にてお知らせしますので、ご確認ください。」
3. 取得処理中も他画面の操作が可能（バックグラウンド処理）
4. 取得完了後、ベル通知を送信
5. 一部店舗でエラーが発生した場合は通知内のファイルに対象店舗名を記載

## クチコミ投稿通知機能

⚠️ **デフォルトはOFF。ONにする場合は担当まで連絡。**

新規クチコミが投稿された際に担当者へ通知メールを送信する機能。

**通知タイミング：** 1日3回のバッチ処理（8・14・20時）で新着クチコミを取得し、該当する場合に通知メールを送信。

### ネガティブアラート

ネガティブなクチコミが入った際にアラート通知を送信。クチコミ管理メニューに「！」マークが表示される。

| バッチ回 | 処理時間帯 | 「！」表示期間 |
|---------|-----------|-------------|
| 1回目 | 8時〜17時頃 | 8時〜17時 |
| 2回目 | 14時〜23時頃 | 14時〜23時 |
| 3回目 | 20時〜翌朝5時頃 | 20時〜翌日朝5時 |

⚠️ 3回のバッチが連続処理されるため、「！」マークがずっと表示され続けているように見える場合がある。

### キーワード設定（クチコミ投稿通知）

店舗詳細設定でキーワードを設定すると、そのキーワードを含むクチコミが投稿された場合にも通知メールを送信。

- 設定場所：店舗詳細ページ下部「キーワード設定（クチコミ投稿通知）」
- 最大**100個**まで登録可能
- ⚠️ 会社詳細設定では「キーワード設定（クチコミ投稿通知）」は表示されない

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/48277405645081
