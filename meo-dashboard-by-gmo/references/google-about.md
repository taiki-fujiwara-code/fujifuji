## GBPの「オーナー」「管理者」の違い

**違いのポイント：** リスティングの削除権限・ユーザー管理権限の有無。

| 権限 | オーナー | 管理者 |
|------|---------|--------|
| ビジネス情報の編集 | ✅ | ✅ |
| 写真・動画の追加 | ✅ | ✅ |
| 投稿の作成・管理 | ✅ | ✅ |
| クチコミへの返信 | ✅ | ✅ |
| インサイトの確認 | ✅ | ✅ |
| 他ユーザーの招待・承認・削除 | ✅ | ❌ |
| ビジネスプロフィールの削除 | ✅ | ❌ |
| オーナー権限の譲渡 | ✅ | ❌ |

⚠️ オーナー権限を持つ人が退職・異動する場合は速やかに新しいオーナーを任命し権限を譲渡する必要がある。

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/4408644997785

## GBPのステータスの種類

| ステータス | 意味 |
|-----------|------|
| **確認済み** | オーナー確認が完了し、Googleにビジネス情報が公開されている状態 |
| **重複** | 同一住所・同一ビジネス情報が複数登録されていると自動判断された状態 |
| **オーナー確認が必要** | ビジネス登録はできているが、オーナー確認の方法をまだ選択していない状態 |
| **停止中** | ビジネスプロフィールが公開停止。Googleマップ・検索結果に表示されなくなる |

### 「停止中」の主な原因と解決策

**原因：** ガイドライン違反（虚偽情報・禁止キーワード使用等）/ 不正な口コミ投稿等の不正活動 / アカウントの制限

**解決策：**
1. 停止の原因となっているガイドライン違反を修正
2. 違反修正後、Googleに回復リクエストを提出
3. 回復リクエストが却下された場合は再審査請求を行う

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/47722280624153

## オーナー確認の方法

### 1〜10店舗の場合

**① ハガキによる確認（最も一般的）**

1. GBPにログインし、オーナー確認が必要なビジネスを選択
2. 「オーナー確認を行う」または「今すぐオーナー確認」をクリック
3. 提示された方法から「郵送」または「ハガキ」を選択
4. 連絡先の名前を入力し、郵送先住所を確認してリクエストを送信
5. 2〜3週間程度で確認コード記載のハガキが届く
6. GBPにログインし、ハガキに記載された確認コードを入力して完了

⚠️ ハガキが届くまでの間、ビジネス名・カテゴリ・住所などの編集は避ける。編集すると申請が無効になる場合がある。

**② 電話・SMSによる確認**

1. GBPで「オーナー確認を行う」をクリック
2. 「電話」または「SMS」が表示された場合に選択
3. 登録電話番号に確認コードが届く（自動音声またはSMS）
4. 確認コードを入力して完了

⚠️ フリーダイヤル（0120）や自動音声応答システム（IVR）を利用している電話番号では確認できない場合がある。

**③ 動画による確認**

1. GBPで「動画による確認」を選択
2. スマートフォンで以下を撮影して提出：
   - ビジネスの外観（通り名・店舗名・サインなど）
   - 内装
   - ブランド名入り設備での営業活動の様子
   - レジやキッチンなどの運営場所
3. Googleが審査し、通常5営業日以内に結果が通知される

### 10店舗以上の場合

一括申請が可能。スプレッドシートを作成してGoogleへ一括確認をリクエストする。

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/4408637250969

## オーナー権限の譲渡手順

1. GBP管理画面を開く
2. 「その他アイコン」（縦3点）→「ビジネスプロフィールの設定」を選択
3. 「ユーザーとアクセス権」を選ぶ
4. 譲渡したいユーザーを選択
5. 編集アイコン（鉛筆マーク）をクリックし「メインのオーナー」を選択して「保存」

⚠️ この操作は現在のメインオーナー権限を持つユーザーのみが行える。新しいオーナーは事前に招待を受け入れアクセス権が付与されている必要がある。

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/4408686764825

## 重複ステータスの対応方法

### 対応方法①：アクセス権限リクエスト

「このビジネスのプロフィールはすでにGoogleに登録されています。管理者になるためのアクセスをリクエストできます。」と表示されている場合。

1. 「アクセス権限をリクエスト」をクリック
2. 指示に従いリクエストを送信
3. 既存管理者が承認するか、Googleが手動で確認（通常3〜7日）

⚠️ 管理者がリクエストに応じない場合、Googleから「ビジネスオーナー確認のための証拠の提出」を求められることがある。

### 対応方法②：コピーを削除

「既存のプロフィールを管理するためのリクエストは承認されました。ビジネスプロフィールからこのコピーを削除できます。」と表示されている場合。

1. 管理画面で「︙」→「ビジネスプロフィールの設定」を押下
2. 「プロフィールのコンテンツと管理者の削除」を押下
3. 「続行」→「削除」を押下

**参照**：https://help-meodash.zendesk.com/hc/ja/articles/4408716965017
