## インサイト系指標

| 用語 | 定義 | 備考 |
|------|------|------|
| **全体閲覧ユーザー数** | GBPが表示されたユーザー数 | 1ユーザー1日1回のユニークカウント |
| **全体アクション数** | 各アクションボタン（ウェブサイト・ルート・電話）が押された合計回数 | ユニークカウントではない。同一ユーザーの同日複数回も都度カウント |
| **全体アクション率** | 閲覧ユーザー数に対するアクション発生率 | 全体アクション数 ÷ 全体閲覧ユーザー数 |
| **ウェブサイトクリック数** | GBP上の「ウェブサイト」ボタンがクリックされた回数 | アクション回数の内訳 |
| **経路案内クリック数** | GBP上の「経路案内」ボタンがクリックされた回数 | アクション回数の内訳 |
| **電話ボタンタップ数** | GBP上の「電話」ボタンがタップ/クリックされた回数 | **通話数ではない**。ボタンタップ後にキャンセルしてもカウントされる |
| **Google予約回数** | 「席を予約」ボタンから予約が完了した回数 | ボタンクリック数はカウント外 |
| **メニュークリック数** | Googleマップのメニュータブを押した回数 | 飲食店のみ表示。同一ユーザーの複数回は1カウント |
| **注文回数** | 「注文する」ボタンから注文が完了した回数 | 飲食店のみ表示 |
| **データ保管期間** | インサイトデータの保管期間 | **18か月**。それ以前のデータは表示不可 |

## 順位・KPI系指標

| 用語 | 定義 | 備考 |
|------|------|------|
| **3位以内率** | 1ヶ月間において、設定キーワードがGoogle検索の3位以内に入った比率 | 計算式：3位以内に入った回数 ÷（キーワード数 × 日数）|
| **GBPの検索総数** | 直近1ヶ月のキーワード検索数の合計値 | キーワード分析画面で確認 |
| **ローカル検索表示なし** | 検索結果にマップ表示がされていない状態 | 特殊ステータス |
| **競合ナレッジパネル** | 検索結果に競合他社1社のみのナレッジパネルが表示されている状態（マップなし・1社のみ） | 特殊ステータス |
| **想定来店者数** | アクション数（電話・ルート・ウェブサイト）にGMO TECH独自調査のCV率を乗じた推定値 | **実際の来店者数ではない**。あくまで想定数値・目安 |

## クチコミ分析系指標

| 用語 | 定義 | 備考 |
|------|------|------|
| **感情分析値** | クチコミに含まれるキーワードの感情分析値 | AWSの感情分析（ポジティブ・ネガティブ）より計算 |
| **話題数** | キーワードが含まれるクチコミが話題にあがった数 | クチコミ傾向分析で使用 |
| **評価平均点** | キーワードが含まれるクチコミの評価平均点 | クチコミ傾向分析で使用 |
| **検出ワード** | キーワードに係る形容詞。検出ワードを含むクチコミの比率も表示 | クチコミ傾向分析で使用 |
| **ハイライトワード** | GBPのレビュー欄上部に記載されている、レビューで多く含まれているワード | 毎月1日にデータ取得 |
| **仮登録** | クチコミ傾向分析のキーワードの一時登録。一定期間後に削除される | 継続分析には本登録が必要 |
| **本登録** | クチコミ傾向分析のキーワードの正式登録。翌朝のバッチ処理後にデータが反映される | — |

## データダウンロード系

| 用語 | 定義 | 備考 |
|------|------|------|
| **平均値** | 対象インサイト情報の合計 ÷ 指定期間の日数 | 当日を含む期間を指定した場合は直近5日を除いて算出 |
| **キーワード別ランキングデータ** | 設定キーワードの順位データのCSV出力 | データダウンロード画面から出力 |
| **パフォーマンスレポートCSV** | インサイトデータのCSV出力 | データダウンロード画面から出力 |

## 機能・画面固有の用語

| 用語 | 定義 | 備考 |
|------|------|------|
| **改ざん防止機能** | GBPの情報が第三者によって変更された場合、Dashboard登録情報に自動再更新する機能 | 処理タイミング：1日3回（朝/昼/夕方） |
| **グループ** | 複数店舗をまとめて管理するための単位。一括編集・一括投稿等が可能 | — |
| **ワークフロー（WF）** | 投稿・クチコミ返信等の承認フロー機能 | — |
| **多地点順位チェック** | 複数地点からの順位を毎週計測する機能 | 計測日：毎週木曜日 |
| **インサイトクロス分析** | アクション数と3位以内率を組み合わせて施策効果を分析する画面 | — |
| **想定来店者数** | インサイトクロス分析内の直近3ヶ月インサイト情報に表示される推定来店者数 | CV率はGMO TECH独自調査値 |
| **キーワード分析** | 上位表示キーワードの順位推移レポート（店舗ページ限定機能） | 個店のみ |
| **カレンダー順位レポート** | GBP流入時の検索キーワード順位を1ヶ月単位でカレンダー表示する機能（店舗ページ限定） | 個店のみ |
| **IPアドレス制限** | 指定IPアドレス以外からのログインを制限する機能 | 要申込。1アカウントにつき最大5IPまで |
| **MFA（多要素認証）** | ログイン時の二段階認証機能。ID・パスワードに加えて6桁の認証コードが必要 | 要申込。認証コード有効期限10分 |
